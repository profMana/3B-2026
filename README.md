# 🚀 3B info - Esercizi Web Development (HTML, CSS, JavaScript)

Raccolta di esercizi di **Web Development frontend**. 
In questo repository sono raccolti tutti gli esercizi di **HTML5**, **CSS3** e **JavaScript** svolti in classe

---

## 📂 Struttura del Repository

Il progetto è organizzato in cartelle tematiche, ordinate per livello di complessità o per tecnologia:

```text
├── 01-HTML/         # Struttura delle pagine, tag principali e moduli
├── 02-CSS/          # Layout (Flexbox, Grid), animazioni e responsive design
├── 03-JavaScript/   # Logica, manipolazione del DOM, eventi e API Fetch
└── 04-Bootstrap/    # Piccole applicazioni complete (es. Todo App, Calcolatrice)
```

---

## 🛠️ Tecnologie Utilizzate

*   **HTML5:** Struttura semantica e accessibile.
*   **CSS3:** Stile avanzato, variabili CSS, Flexbox e Grid Layout.
*   **JavaScript:** Logica frontend vanilla (senza framework), programmazione asincrona e gestione del DOM.

---

## 📈 Obiettivi  

*   [ ] Comprendere a fondo la semantica HTML.
*   [ ] Creare interfacce completamente responsive (Mobile-First).
*   [ ] Padroneggiare la manipolazione del DOM con JavaScript puro.
*   [ ] Usare Bootstrap per semplificare la scrittura dell'interfaccia grafica.
